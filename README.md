# Mama Organizer

Отдельный мобильный органайзер на Supabase.

## Возможности
- вход по email и паролю;
- добавление задач;
- ученик и класс;
- заметки;
- отметка выполнения;
- редактирование и удаление;
- сортировка по имени ученика и классу;
- адаптивный интерфейс для телефона и компьютера.

Данные хранятся в отдельном Supabase-проекте и защищены RLS: пользователь видит только свои задачи.
